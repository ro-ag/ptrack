    Keyboard reference

    Desktop and terminal shortcuts

    Desktop handles workspace shortcuts inside its webview; terminal-focused shortcuts preserve common shell behavior where a selection or platform convention changes the result.

    Desktop workspace

    Native menu accelerators

    Only macOS assigns native application-menu accelerators: Cmd+O opens a project, Cmd+, opens the Settings dialog, and Cmd+1/Cmd+2 select Board/Intelligence (Overview). The Windows and Linux native menus deliberately do not assign these accelerators. The separate Desktop webview shortcuts above may still handle their Ctrl forms while the webview has focus.

    Switch Project, Close Project, Toggle Terminal Panel, and Command Palette have no native menu accelerator.

    Ctrl+C keeps shell semantics when nothing is selected. On Windows/Linux it copies only when terminal text is selected; without a selection it remains available to interrupt the running process. Ctrl+Shift+C is the unambiguous copy chord.

    Command palette

    After opening the palette with Cmd+K or Ctrl+K, type to search plans, tasks, and notes. Use ↑/↓ to select, Enter to activate, and Esc to close. The palette searches project records; it does not execute commands.

    TUI keys

    The terminal interface supports arrow keys and Vim-style h/j/k/l navigation where a screen has horizontal and vertical selection. ? or F1 opens its command menu, 1–5 select screens, and q or Ctrl+C quits. See the complete TUI key table for global, menu, detail, and screen-specific actions.
