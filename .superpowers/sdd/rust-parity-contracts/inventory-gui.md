`frontend/wailsjs/` (generated surface), `frontend/src` adapter layers. The
bound type is a single `*gui.App` (`internal/gui/app.go:27`), bound via

## Notes / surprises

- The `v0.21.0` surface has **63** bound methods. `OpenHelpDestination` and its Help Center allowlist were added after the tag and are intentionally absent; GUI-012 is an internal shared updater fence, not a bound method.
- `gui.AgentWorkflowKind` is referenced in App.d.ts:98 but **not defined anywhere in models.ts** — the frontend passes a plain string; the enum values live only in Go (`internal/gui/agent_workflow_registry.go:17-24`, note camelCase `pullRequest`).
- Casing is deliberately mixed on the wire: `model.*` (capabilities/audits), `capability.ConnectionDiagnostic`, and `gui.CapabilityView.effective_scope` are snake_case; everything else camelCase. `ConnectionDiagnostic` has a field literally named `class`.
- `terminal:status` has no frontend subscriber — emitted and test-pinned but unconsumed; `terminal:exit` is consumed with an early-exit cache (exit may arrive before the WebSocket connects).
- `AssociateTerminalV2` / `AssociateAgentRunV2` are bound and generated but have **zero frontend callers**; all association edits go through `MutateTerminalAssociationV2`.
- The frontend never parses backend error strings (verbatim toast only), but the exact strings above remain the user-visible surface and several are asserted by Go tests; the build test pins some client-visible call shapes exactly.
- Time formats differ by site: RFC3339 UTC for board/task/snapshot fields; RFC3339Nano UTC for handoff/workflow envelopes, transition challenge `expiresAt`, notifications, evidence; heatmap buckets by **host-local** day (timezone-dependent output).
- Reads with hidden side effects: runtime projection records terminal activity, stale worktree claims and stale handoff envelopes are deleted during snapshot reads, registries prune TTL-expired entries on every read/write. Observable only through subsequent behavior, but a rewrite should match.
- `GetCapabilityAuditsV2` silently clamps bad limits to 25; `GetAgentIntelligenceV2.eventBounds` mixes filtered `shown` with unfiltered `total`; `DriftSnapshot.state` is always `ready` (incompleteness only via `incomplete`/`bounds.more`); detach-of-detached terminal is an error (`invalid association target: terminal is already detached`), not a no-op.
- Updater recovery writes/reads `.stage-*` dirs and `.pending-apply-*.json` under the global home with a hard 64-stage cap; the preference is the literal strings `"true"`/`"false"` in the global bbolt DB — coexistence with the Go app requires reading these formats.
- Terminal stream data plane is a raw WebSocket with a custom ack/window protocol (GUI-124) entirely outside the Wails boundary — easy to miss in a Tauri port.
- Event payloads are inconsistent by design: bare uint64 (runtime/data-changed), full struct (update:state-changed), nil (menu events), typed structs (terminal:*) — no envelope anywhere.
- `CloseProject`'s returned `state.status` is `closed` while the app's settled status afterwards is `welcome`; the frontend relies on seeing `closed` then re-polls after 350 ms.
